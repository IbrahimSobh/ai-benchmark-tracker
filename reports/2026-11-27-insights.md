# Frontier AI benchmarks: summary and insights, update of 2026-11-27

Written from [2026-11-27-report.md](2026-11-27-report.md) (data collected 2026-11-27). If that tables file is collected again, check these insights still match.

## Summary

The leader changes from one benchmark to the next, and the top places are often close. Claude Fable 5.2 leads SWE Atlas, Scale's test of professional coding work, and Gemini 4 Argon leads MCP-Atlas, a test of using tools and apps through MCP connections. Kimi K3.1 Pro leads Terminal-Bench 4.0, a test of coding tasks done in a computer terminal, but no margin is published. Several runners-up are too close to call with those leaders, so no single model wins every test.

## Insights

1. **Claude Fable 5.2 leads Scale's professional coding test, but five other models are too close to call with it.** SWE Atlas is Scale's test of professional coding work: answering questions about a codebase, writing tests and refactoring. Claude Fable 5.2 scores 80.5%, but Claude Opus 5.5 (77.5%), Claude Fable 5.1 (76.5%), and Gemini 4 Neon, Gemini 4 Hydrogen and Gemini 4 Carbon (72.0%, 72.0% and 71.5%) are too close to call with it. ([source](https://labs.scale.com/leaderboard/swe-atlas))

2. **Kimi K3.1 Pro leads the terminal coding test at 67.2%, but no margin is published.** Terminal-Bench 4.0 is a set of coding tasks done in a computer terminal. The next model, Gemini 4 Carbon, scores 65.2%, and the table publishes no margin for any runner-up, so the lead cannot be called clear. Every model in the table shows "same" in the Change column. ([source](https://artificialanalysis.ai/evaluations/terminalbench-4-0))

3. **Gemini 4 Argon leads the tool-use test at 90.7%, with two models too close to call.** MCP-Atlas tests using tools and apps through MCP connections to finish multi-step tasks. Muse Spark 1.1 (88.1%) and Claude Fable 5.1 (87.2%) are too close to call with Gemini 4 Argon, while Claude Opus 5 is behind it at 85.8%. ([source](https://labs.scale.com/leaderboard/mcp_atlas))

4. **Separately, in public votes on real-task agents, Claude Fable 5.2 leads with a score of 0.274, and the table shows what each model costs.** Agent Arena is a set of public votes where people rate AI agents on their own real tasks. The leader's median cost is $9.15 per task. Gemini 4 Carbon scores 0.161 at $1.35 per task, which is fourth in the table and far cheaper. ([source](https://arena.ai/leaderboard/agent))
